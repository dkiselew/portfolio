The platform

I started on Infrastructure (2014–2018), building the PHP microfrontend layer that every upwork.com page sat on. When the company standardized on Vue, I moved to the frontend track and stayed through the company-wide migration of Upwork’s frontend core — work that touched every product team.

The job was evolving what already shipped, not throwing it away: a shared core, fewer one-off stacks, better developer experience. I helped raise the floor so the next page didn’t start from scratch.

Design system

Co-built Upwork’s shared UI component library. Day-to-day with design: Figma to Storybook, implemented in Vue and React. Fidelity and reuse — components high-traffic teams could trust, not a parallel visual language. Filling gaps, refining patterns, keeping the system honest as the product grew.

Proposal Manager

Built the UI from scratch — a light CRM where clients review applicants, filter them, and send invites. One engineer per feature: the design conversation, implementation, tests (Playwright, Jest), and rollout sat with me. Shortlisting and inviting became noticeably faster.

AI Interviews

Built the interview review page: a custom video player with YouTube-style controls and an AI-generated summary of each interview. Clients screen from a recording instead of scheduling a live call. The player had to feel native to the product — not a third-party widget dropped on the page. Interaction work that later drew on OneLinePlayer.

How we worked

Features from scoping to production, including the UX conversation before the PR. I didn’t wait for a pixel-perfect spec on every state — I asked for intent, then made the call in code. I reviewed what teammates shipped and caught UI inconsistencies at a glance. Remote, owned end to end, written down clearly enough that design and product could move without a meeting.

Hard

  • React and TypeScript — the daily language. Vue and Nuxt are depth from Upwork, not a closed stack. Next.js is a framework I pick up; the craft is the frontend.
  • Design systems — Storybook, Figma, day-to-day with design. Shared libraries in Vue and React. Improve the system that exists.
  • CSS and interaction — states, motion, spacing, type. The button on this page is Motion; the habit is making a surface feel native.
  • Accessibility and performance — on pages that take tens of millions of visits a month, not as a later pass.
  • Tests and systems — Playwright, Cypress, Jest. Microfrontends and platform migrations: evolve the whole, don’t rewrite the page.

Soft

  • Thinks like a designer — I catch when something is technically correct and still doesn’t feel right, and I have an opinion about the fix.
  • Comfortable in ambiguity — I ask for intent, then make UX decisions in code. No spec for every hover state.
  • Remote and async — I write clearly, support the next person, and don’t wait for permission to move.
  • Cross-functional — design, product, and marketing (Veeam). I can explain a technical trade-off to someone who doesn’t write CSS.
  • No-ego craft — review, raise the bar, evolve instead of rewrite. Ship when it’s good enough to learn from.
