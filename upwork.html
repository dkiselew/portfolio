Design system

Co-built Upwork’s shared UI component library. Day-to-day work with the design team: Figma to Storybook, implemented in Vue and React. The job was fidelity and reuse — components that product teams could trust on the highest-traffic pages, not a parallel visual language.

Proposal Manager

Built the UI from scratch — a light CRM where clients review applicants, filter them, and send invites. The team model was one engineer per feature, so design conversations, implementation, tests (Cypress, Jest), and rollout sat with me. Shortlisting and inviting became noticeably faster.

AI Interviews

Built the interview review page: a custom video player with YouTube-style controls and an AI-generated summary of each interview. Clients can screen from a recording instead of scheduling a live call. The player had to feel native to the product, not like a third-party widget dropped on the page.

How we worked

Features from scoping to production, including the UX conversation before the PR. I reviewed what teammates shipped and caught UI inconsistencies at a glance. Earlier, on the Infrastructure team (2014–2018), I built PHP microfrontend infrastructure for upwork.com pages, then moved to the frontend track when the company standardized on Vue.
